# The Town Villa Coorg

Complete website design, development, content, SEO and GitHub Pages implementation plan

Multi-page static website

Mobile-first

SEO-focused

The Town Villa Coorg website should be a premium, modern homestay booking website that presents the property as an excellent accommodation choice in the heart of Madikeri, Coorg.

Its main objective is to convert Google Search visitors, Google Business Profile visitors and Google Ads traffic into direct phone calls and WhatsApp booking enquiries.

The most important selling points are the property's central Madikeri location, proximity to Omkareshwara Temple, four spacious two-bedroom villas, family and group accommodation, and convenient access to the town's popular attractions.

### Shared header and footer loading

GitHub Pages serves static files, so it does not process server-side HTML includes by itself. Use one of these two approaches:

Preferred: At build/deploy time, assemble `header.html` and `footer.html` into each generated page using a lightweight build script. This keeps navigation crawlable in the initial HTML and avoids delayed layout shifts.

Alternative: Load `components/header.html` and `components/footer.html` using JavaScript `fetch()`. This is workable but less robust for initial rendering, accessibility and crawlers. In that case, reserve layout space and provide fallback navigation.

Maintain all paths relative to the site base URL, so the same project works on a GitHub repository subpath or a custom domain.

| Metric                    | Target                                    |
| ------------------------- | ----------------------------------------- |
| Largest Contentful Paint  | 2.5 seconds or less                       |
| Interaction to Next Paint | 200 ms or less                            |
| Cumulative Layout Shift   | 0.1 or less                               |
| Lighthouse performance    | Aim for 90+ on mobile                     |
| Layout                    | No horizontal overflow at 320px+          |
| Images                    | Properly sized, compressed and responsive |

Accessibility and reliability

- Semantic HTML and visible keyboard focus.
- Good color contrast for text and buttons.
- Accessible labels for enquiry fields.
- Proper `aria-label` descriptions for icon-only controls.
- No autoplay audio, unnecessary animation or disruptive popups.
- Respect reduced-motion preferences.
- Test navigation and enquiry links across mobile browsers.

Analytics and marketing

Implement Google Analytics 4 and Google Tag Manager where consent and configuration requirements are met. Track meaningful booking events including `click_call`, `click_whatsapp`, `submit_booking_enquiry` and `click_directions`.

For Google Ads, configure qualified call and enquiry conversions rather than treating every page view as a lead. Test event firing and prevent duplicate conversions.

## 15. Development phases and acceptance criteria

1. Phase 1 — Brand and website foundation

   Finalize typography, colors, logo versions, reusable spacing and button styles. Set up repository, GitHub Pages deployment and shared navigation architecture.
2. Phase 2 — Homepage and accommodation pages

   Build the responsive homepage, Villas, Amenities, About and Gallery pages. Integrate uploaded property photos and verified descriptions.
3. Phase 3 — Booking and mobile conversion

   Implement sticky Call/WhatsApp controls, enquiry form, phone links, booking CTAs and contact page. Test prefilled enquiry messages.
4. Phase 4 — Attractions and informational content

   Develop location, nearby places, attraction guides and useful travel information. Add verified maps and internal linking.
5. Phase 5 — Technical SEO and tracking

   Configure titles, descriptions, canonicals, structured data, sitemap, robots directives, analytics and search verification.
6. Phase 6 — Quality assurance and publication

   Test all pages on mobile, tablet and desktop; confirm photo loading, navigation, calls, WhatsApp enquiries, page indexing and final publishing.
